# GFSSM AI Coach · 学生版

面向 GFSSM 学生的自主学习教练（纯前端网页，无需联网、无需安装）。

**在线使用：https://gfssm-ai.itccc.app**

## 使用方式

- 在线版：直接打开 https://gfssm-ai.itccc.app（推荐，手机/平板均可）
- 离线版：双击打开 `index.html`（建议 Chrome / Edge 浏览器）。整个工具就是这一个文件夹，拷贝给任何学生都能直接用。

> 修改代码后 push 到 `main` 分支，Vercel 会自动重新部署。

## 核心设计：环境档案（每年自适应）

GFSSM 每年换目标场地，所以**所有会变的数字都不写死在内容里**，而是集中在「环境档案」一层：

- **换场地**：侧栏顶部「当前环境」→ 从 8 个预设里选（月球 / 火星 / 木卫二冰下 / 土卫六 / 小行星 / 近地轨道 / 地月空间 / 金星云层），或上传 RFP 自动识别。
- **自动识别**：读取 RFP 全文，匹配天体关键词 + 抽取深度、压力、辐射、时延等数值（只抽可靠项；"0.8 g"这类人工重力不会被误当天然重力）。识别结果可手动修改。
- **全站联动**：讲解页的参数表、公式算例、条件段落（冰下 / 非冰下内容自动切换），以及自测里的环境参数题（E1–E10），全部按当前档案实时计算。换一份 RFP，题目答案自动重算。
- **RFP 不一致提醒**：在 RFP 分析页，若检测出的场地与当前档案不同，会提示去更新。

## 它做什么 / 不做什么

**做四件事：**

1. **学知识**（模块 00–12）：项目认知与 RFP 读法、太空环境（参数表按你的场地生成）、人工重力（转速-半径表按目标重力实时算）、空间尺度与分区、建造次序、空气与水循环、废物与食物闭环、人居与人因、基础设施、能源电力（光伏可行性按你的辐照分档）、进度成本、呈现与评审。
2. **做自测**（24 通用题 + 2 术语题 + 10 环境参数题）：每题带解析与计算步骤，错题自动归因到知识模块，生成模块正确率报告，可"只做错题"。参数题随环境档案变化。
   - **每个知识模块底部都有"本节小测"卡片**：一键只做该模块的题，做完回全部题库。
   - **每页顶部有环境提示条**：显示当前档案（场地 / 重力 / 辐射 / 外压），一键进入环境档案修改；未设定时显示"待填"并引导设定。
3. **分析 RFP**：上传本年 RFP（PDF/DOCX/TXT）或粘贴文字，本地解析出章节、Deliverable 交付物清单、must/at least 硬指标、关键数字，并按评审规则库给出每节的**最小达标线、评审视角、追问清单、常见坑**，同时关联到对应知识模块。内置 2027 Galileo 示例可一键载入。
4. **环境档案**：查看 / 修改当前场地的 12 项关键参数（含"每一项决定什么"的说明）。

**不做的事（Honor Code 边界）：** 不生成方案、参数、图纸、PPT 文字。所有分析都以"甲方要什么、评委看什么、你该问自己什么"结束。

## 附带工具

人工重力（R↔rpm）、环带面积、应急储能（kW×天→kWh）、光伏面积、水回收补给、通信时延，共 6 个即时计算器。

## 交互配图（Anatomy）

模块 03 与 06 各有一张可操作的等距配图，纯 SVG + 原生 JS，无外部依赖，离线版同样可用：

- **图 3-3 人工重力试验台**（模块 03）：拖旋钮改目标重力、拖曲柄改半径；转速表、试块压缩量与读数由同一个 `a = ω²R` 模型驱动，红线标出 2 rpm 舒适上限。
- **图 6-1 闭环生保试验台**（模块 06）：点击阀门（或按空格）把甲烷送进热解器，观察氢收支从 −78 kg/天 回到 +14 kg/天，补氢浮子与 O₂ 读数联动。

配图脚本按需加载（`figures/*.js`），不进首页首屏；构建与数字模型说明见 [`figures/README.md`](figures/README.md)。

## 维护指南（给老师）

- **改题**：`data-quiz.js`（通用题）、`data-quiz-env.js`（参数题模板，数值自动代入）。
- **改知识内容**：`data-learn-a/b/c.js`。其中 `{{gNat}}`、`{{radDayShow}}` 等占位符会自动替换成当前档案的值；`{{#if icy}}…{{/if}}` 是条件段（仅冰下场景显示）。
- **加场地**：在 `data-env.js` 的 `SCENES` 里加一条即可，全站（含题目）自动支持。
- **改配图**：改 `figures/build-gravity.mjs` / `build-life.mjs` 后运行 `node figures/build-gravity.mjs`、`node figures/build-life.mjs`；页面里用 `<div class="anatomy-slot" data-figure="gravity|life"></div>` 放置。
- 预设数值为教学典型值，**凡 RFP 原文给了的数一律以原文为准**——档案页支持手动改数。

## 技术说明

- 纯静态页面，进度与环境档案存在浏览器 localStorage，不上传任何数据。
- PDF 解析使用本地化的 pdf.js（`libs/` 目录），无需联网。
- 扫描版（图片型）PDF 提取不了文字，请用 WPS/Word 另存为 .docx 或直接粘贴正文。
